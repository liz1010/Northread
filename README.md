# Northread

> 让每一次阅读，都有方向。

Northread 是一个基于个人目标的 AI 阅读与资讯助手。它从书籍、RSS、博客、论文、
Newsletter、YouTube、播客和 Twitter/X 等来源中寻找真正值得阅读的内容，
帮助用户减少信息噪声，
把阅读转化为知识、方法与行动。

它不以点击率、停留时间或无限信息流为目标，而是回答三个更重要的问题：

1. 这篇内容是否能让我离目标更近？
2. 为什么值得现在读？
3. 阅读之后，我真正理解、保留和应用了什么？

## 核心主张

**You are what you read.**

传统推荐算法根据点击记录猜测用户还想消费什么；Northread 从用户想达成的
目标出发，判断其需要形成哪些能力、当前缺少什么认知，以及下一步最值得读什么。

> 不推荐让你停留更久的内容，只推荐让你离目标更近的内容。

## 第一阶段

首个版本将聚焦一个简单而完整的体验：

- 创建个人目标与背景档案
- 添加 RSS、网站、单篇文章、书籍、视频频道或社交账号
- 逐步接入微信读书等阅读平台，同步书架、进度、划线与笔记
- 设置重要信源、降低噪声来源，并让 AI 根据反馈动态调整推荐权重
- 根据目标对内容进行评分、去重和排序
- 每天推荐少量真正值得读的内容，并解释推荐原因
- 阅读后沉淀知识卡片、反思问题和行动项
- 用每周复盘展示阅读如何推动目标

完整的产品构想请阅读 [产品愿景](docs/product-vision.md)，个人可用版的开发路径请阅读
[实施计划](docs/implementation-plan.md)。

## 界面概念

界面以中文为主，内容同时支持中英文材料——英文原文配中文推荐理由和中文 AI 解释。

- [今日首页](docs/assets/northread-today-concept.svg)：一条最值得读的、两条有时间再读的、
  今天过滤掉了什么、本周目标进展，以及昨天的阅读留下了什么。页面到此为止，
  下面没有信息流，也没有未读数。
- [三栏阅读工作台](docs/assets/northread-workspace-concept.svg)：每份材料都通过
  “目标 → 知识缺口 → 材料角色”建立明确关联；分数可以展开成构成项，不出现裸分数；
  推荐附带置信度、阅读建议和已知的不足。

两张图都是手写 SVG，设计 token 集中在文件头部，换配色只改那一段。
配色的推导和取舍见 [三套配色方向](docs/assets/palette-directions.svg)。
