# Northread

> 让每一次阅读，都有方向。

Northread 是一个基于个人目标的 AI 阅读与资讯助手。它从书籍、RSS、博客、论文、
Newsletter、YouTube、播客和 Twitter/X 等来源中寻找真正值得阅读的内容，
帮助用户减少信息噪声，
把阅读转化为知识、方法与行动。

它不以点击率、停留时间或无限信息流为目标，而是回答三个更重要的问题：

1. 这篇内容是否能让我离目标更近？
2. 为什么值得现在读？
3. 阅读之后，我真正理解、保留和应用了什么？

## 核心主张

**You are what you read.**

传统推荐算法根据点击记录猜测用户还想消费什么；Northread 从用户想达成的
目标出发，判断其需要形成哪些能力、当前缺少什么认知，以及下一步最值得读什么。

> 不推荐让你停留更久的内容，只推荐让你离目标更近的内容。

## 第一阶段

首个版本将聚焦一个简单而完整的体验：

- 创建个人目标与背景档案
- 添加 RSS、网站、单篇文章、书籍、视频频道或社交账号
- 逐步接入微信读书等阅读平台，同步书架、进度、划线与笔记
- 设置重要信源、降低噪声来源，并让 AI 根据反馈动态调整推荐权重
- 根据目标对内容进行评分、去重和排序
- 每天推荐少量真正值得读的内容，并解释推荐原因
- 阅读后沉淀知识卡片、反思问题和行动项
- 用每周复盘展示阅读如何推动目标
